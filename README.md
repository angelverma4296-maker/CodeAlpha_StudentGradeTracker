# Student Grade Tracker 🎓

A Java-based **Student Grade Tracker** developed to manage student marks and calculate academic performance. This project demonstrates the use of Java programming fundamentals, calculations, conditional statements, and data management.

## 📌 About the Project

The Student Grade Tracker is a beginner-friendly Java project created as part of the **CodeAlpha Java Internship**. It aims to simplify the process of recording student marks and evaluating academic performance.

## ✨ Features

- 📝 Manage student marks and grades.
- 📊 Calculate average marks.
- 🎯 Determine grades based on performance.
- 📋 Display student performance details.
- 💻 Simple and easy-to-use Java implementation.

- **Programming Language:** Java
- **Concepts:** Variables, data types, conditional statements, loops, and methods

## 🚀 Getting Started

### Prerequisites

- Java Development Kit (JDK) installed on your computer.
- A code editor or IDE such as VS Code, IntelliJ IDEA, or Eclipse.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/angelverma4296-maker/CodeAlpha_StudentGradeTracker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd CodeAlpha_StudentGradeTracker
   ```

3. Open the project in your preferred Java IDE.

### Run the Project

If your project contains a standalone Java file named `Main.java`, compile and run it using:

```bash
javac Main.java
java Main
```

If your main Java file has a different name or your project uses packages, update the commands accordingly.
